## 한국어

기존 2.3.6 설치 파일의 설치 안내 및 `l10n_build/SOURCE_OFFER.txt`에 적힌 “전체 대응 소스가 함께 배포되는 ZIP에 있다”는 설명을 정정합니다. ZIP에는 공개 Calc/Global 소스와 수정 자료가 있지만, 배포된 Core·analysis Core·Loader·캡처 DLL 5개의 정확한 전체 대응 소스가 모두 있지는 않습니다. 공개 원본 파일 121개와 라이선스 기록을 보완해도 이 네이티브 소스 누락은 남습니다.

이번에는 설치 파일 자체를 교체하지 않았으므로 설치 화면·설치 폴더의 기존 문구는 그대로 남습니다. 이 정정과 [현재 소스 안내](https://github.com/LuinDe/NTE-Drive-Calc-Global/blob/main/SOURCE_OFFER.md)를 함께 읽어 주세요. 이번 문서 정정은 모든 재배포 조건 충족을 의미하지 않습니다.

## 中文

更正现有 2.3.6 安装说明及 `l10n_build/SOURCE_OFFER.txt` 中“随附 ZIP 包含完整对应源码”的说法。ZIP 提供公开 Calc/Global 源码及修改材料，但没有包含所分发 Core、analysis Core、Loader 和 5 个捕获 DLL 的全部精确对应源码。补充 121 个公开原本文件及许可记录后，这一原生源码缺口仍然存在。

本次没有替换安装包，所以安装界面和安装目录内的旧文字仍然保留。请结合本更正及[当前源码说明](https://github.com/LuinDe/NTE-Drive-Calc-Global/blob/main/SOURCE_OFFER.md)阅读。文档更正不代表所有再分发条件已经满足。

## English

The existing 2.3.6 setup notice and `l10n_build/SOURCE_OFFER.txt` incorrectly state that the accompanying ZIP contains complete Corresponding Source. The ZIP supplies public Calc/Global sources and adaptations, but not all exact Corresponding Source for the distributed Core, analysis Core, Loader and five capture DLLs. Restoring 121 public upstream files and license records does not close that native source gap.

The installer has not been replaced, so its setup and installed notices retain the old wording. Read this correction alongside the [current source notice](https://github.com/LuinDe/NTE-Drive-Calc-Global/blob/main/SOURCE_OFFER.md). This documentation correction does not establish compliance with all redistribution conditions.
